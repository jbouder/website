# doom.wasm

DOOM (1993) compiled to WebAssembly, with the shareware `doom1.wad` baked in.

Prebuilt binary from https://github.com/diekmann/wasm-fizzbuzz (gh-pages
branch, `doom/doom.wasm`) — a wasm32 port of id Software's linuxdoom-1.10
sources (GPL). The shareware WAD is freely redistributable.

Launched by the chat easter egg: type `iddqd` into the assistant.
